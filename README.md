API de Gestão de Vagas - Spring Boot

Projeto desenvolvido para estudos práticos de backend com Java e Spring Boot (tutorial), criando uma API RESTful completa para gerenciamento de vagas de emprego.

🚀 Tecnologias

Java 17

Spring Boot (Web, Data JPA, Validation)

MySQL

MapStruct & Lombok

Swagger

⚙️ Como Executar

Configure suas credenciais do MySQL no arquivo src/main/resources/application.properties.

Abra o terminal na raiz do projeto e execute:

Linux/macOS: ./mvnw spring-boot:run

Windows: mvnw.cmd spring-boot:run

A aplicação vai rodar em http://localhost:8080.

📚 Documentação (Swagger UI)

Com o projeto rodando, acesse no navegador para testar os endpoints:
👉 http://localhost:8080/swagger-ui.html
